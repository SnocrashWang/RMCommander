# README

## 训练心得

### 奖励设计

在同一个阶段中，不同行为的奖励大小要尽可能和当前阶段不同行为采样的比例负相关，避免模型直接在多数采样中挑选一个正奖励的行为，陷入局部最优。

### 课程学习

首个阶段用于学习基本的操作和思路，例如没子弹要买、见到人要打、没血了要回家等。这个阶段不建议设置终局胜利奖励，因为根本不知道是怎么赢的。同时对手的策略要简单一些，控制强度，不然模型会一直得到负的奖励，进化速度很慢。
第二个阶段可以把细节操作的奖励隐藏起来，设计一些宏观方向的奖励，例如击杀成功、占点成功、达成某种胜利进度等等，引导模型的策略方向。这个时候的对手可以稍微增加一些强度，让模型有输有赢。
最后一个阶段需要扩展模型的战术多样性，对手的策略需要尽可能复杂，鼓励模型探索不同的策略。

### UL & UC 哨兵训练设计

为了防止哨兵策略依赖其他机器人策略，我们需要把哨兵策略独立出来，训练两个模型：一个智能体控制哨兵策略（SentryPolicy），另一个智能体控制其他所有机器人（BackgroundPolicy）。
SP必须严格遵守哨兵可观测的状态量，BP可以获取一些对于训练有帮助的上帝视角观测。
BP需要有足够的丰富度，在基本行为训练完毕之后，我们需要为其设计不同分布的奖励，使其策略呈现不同的分布。这个分布可以大致模仿实际比赛中存在的宏观战术，例如远程吊射、地面进攻等。
在训练的过程中，我们需要交替训练SP和BP
