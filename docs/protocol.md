# Protocol

尽管目前规则仍以2025为准，我们仍然以最新的2026版通讯协议为准进行设计

## 全局信息

此类信息发送给己方所有机器人，包含己方的全局信息

### 0x0001

比赛状态，包括比赛类型、当前比赛阶段等

### 0x0002

比赛结果，仅在比赛结束时触发

### 0x0003

己方全部机器人和建筑物血量

### 0x0101

场地事件，包括己方各增益区的占领情况、己方能量机关的激活情况、对方最后一次飞镖命中的时间和类型

### 0x0104

判罚，包括判罚等级、违规机器人的ID和违规次数

### 0x0105

飞镖发射，包括飞镖发射剩余时间、最后一次击中的目标和累计被击中次数

## 机器人信息

此类信息仅发送给对应机器人，只包含该机器人本身的信息

### 0x0201

机器人性能体系数据，包括机器人ID、等级、当前血量、血量上限、冷却、热量上限、功率上限等

### 0x0202

实时底盘缓冲能量和射击热量数据

### 0x0203

机器人位置数据

### 0x0204

机器人增益和底盘能量数据

### 0x0205

伤害状态数据

### 0x0207

实时射击数据，包括发射类型、射速、初速度等

### 0x0208

仅发送给英雄、步兵、哨兵、无人机
允许发弹量

### 0x0209

RFID模块状态，即当前检测到的场地增益卡

### 0x020B

仅发送给哨兵
地面机器人位置数据，包括己方英雄、工程、步兵、坐标
结合自身坐标，唯有哨兵可以得知己方所有地面机器人坐标

### 0x020D

仅发送给哨兵
哨兵自主决策信息，包括成功兑换的允许发弹量、成功远程兑换的允许发弹量、成功远程兑换的血量、是否可以免费复活、是否可以兑换立即复活、兑换立即复活需要花费的金币数、是否处于脱战状态、17mm允许发弹量的剩余可兑换数、当前姿态、己方能量机关是否处于可激活状态

## 雷达信息

需要通过雷达解析信息波获得的敌方信息

### 0x0A01

敌方机器人位置坐标，包括英雄、工程、步兵、无人机、哨兵

### 0x0A02

敌方机器人血量，包括英雄、工程、步兵、哨兵

### 0x0A03

敌方机器人剩余发弹量，包括英雄、步兵、无人机、哨兵

### 0x0A04

敌方宏观状态，即对方各增益区占领状态

### 0x0A05

敌方机器人增益效果，包括英雄、工程、步兵、哨兵的各类增益及哨兵的姿态
